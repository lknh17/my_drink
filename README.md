# 酌味 · 饮品全集（茶 · 酒 · 咖啡博物图志）

与 `my_food`（食味 · 中华风味图志）并立的独立饮品全集系统。针对**茶叶、酒、咖啡**三者截然不同的知识本体（Ontology）与审美气质，采用 **「一枢三馆 · 共享基座 + 独立领域模型 + 独立视觉皮肤」** 架构构建。

## 一枢三馆架构与专属美学

- **总门户（酌味长廊 · 三联屏立面）**：博物馆中庭长廊，包含三座展馆建筑立面卡片、三饮知识本体对照矩阵、「晨茶 · 午咖 · 夜酒」十二时辰引饮流、跨馆全局检索（`⌘K`）与个人品饮护照。
- **第一座大楼 · 茗典 · 中华茶馆（首期全量开馆）**
  - **视觉皮肤 —「天青素宣 · 宋韵山岚」**：素宣纸白 `#F7F5EE` · 汝窑天青 `#35685F` · 岩茶琥珀 `#9A5B25` · 朱泥紫砂 `#A6402C` · 俯视白瓷茶盏拟真茶汤色环。
  - **卷一 · 谱系卷**：六大茶类 + 再加工花茶生化机理、七彩茶汤色谱横轴、`发酵度 × 焙火/陈化度` 二维散点星图。
  - **卷二 · 风土卷**：中国四大茶区 34 省矢量着色地图 + MapLibre GL **20 座核心名茶山场**等高线地形（`topo`）/ 卫星地貌（`satellite`）双底图沙盘。
  - **卷三 · 本纪卷**：**70 款中华传世名茶**单列宽幅精读图志，涵盖风土良种铭牌、干茶/汤色/叶底专业三态审评、四维茶气量化条，以及带实时倒计时器的 **1–6 泡行家司茶冲泡实验卡**。
  - **卷四 · 器道卷**：宜兴紫砂、景德镇盖碗、建阳建盏、汝窑龙泉青瓷、潮汕工夫茶器、银铁煮水器共 **18 席经典茶器**，配交互式「看茶择器」孔隙率与热力学配伍矩阵。
  - **卷五 · 茶脉卷**：秦汉粥茶 → 唐煎 → 宋点 → 明瀹 → 清工夫 → 当代风土六幕千年流变长卷，以及二十四节气四时饮茶历。
- **第二座大楼 · 醺典 · 中外酒馆（全境开馆 · 一院六境）**
  - **国酿 · 中国白酒馆**：羊脂白瓷 × 朱砂陶坛 × 鎏金曲印；收录 **60 款中国白酒**、十二香型宗谱、六大黄金名酒带、14 座核心产区、固态酿造工序与 10 件中华酒器。
  - **麦律 · 啤酒与精酿馆**：麦芽暖奶油 × 酒花翠绿 × 铜釜泡沫；收录 **32 款中外啤酒**、8 类风格、SRM 2–42 色阶、IBU×ABV 实验室与 8 种专业杯型。
  - **四座独立专馆**：古越黄酒 8 款、风土葡萄酒 **32 款四卷全集**、橡木世界烈酒 **32 款四卷全集**、微醺鸡尾酒 8 款；全院合计 **172 款佳酿**。
- **第三座大楼 · 咖典 · 精品咖啡馆（全集开馆 · 六卷大成）**
  - **视觉皮肤 —「生豆羊皮纸 · 烘焙实验室」**：水洗羊皮纸 `#F4EFE6` · 浓缩深棕 `#2B1911` · 焦糖梅纳棕 `#C86D3B`。
  - 六卷涵盖树种后制、庄园风土、**32 款世界与云南寻豆**、**16 款咖啡饮品配方**、7 大冲煮流派、**20 件专业器具**与 10 座城市咖啡生态。

## 技术栈

- React 18 + TypeScript 5 + Vite 6
- MapLibre GL 5 + 中国 34 省级行政区 GeoJSON + 本地磁盘瓦片缓存代理（兼容 `my_food` / `dili` 的 `tiles-cache`）
- `hub.yaml` 原生接入 `my_web_center`（路由前缀 `/drink/`，`portHint: 5197`）

## 本地开发与构建

```bash
npm install
npm run dev        # 默认 http://localhost:5197
npm run build      # tsc --noEmit && vite build
npm run preview    # 默认 http://127.0.0.1:4177
```

## 饮品与器物实拍图语义巡检

```bash
python3 scripts/drink_photo_audit.py --only-missing --workers 12
```

全馆 **494 项**实拍资产由 `public/photos/semantic-ledger.json` 记录分辨率、来源与语义分数；本地开发时可在任一馆顶栏点击「🖼️ 配图校准」，或按 `Cmd/Ctrl + Shift + I` 打开巡检工作台。工作台支持关键词检索候选图、直链换图、高清门槛校验及一键跳转所在展席。
